## Fight Site

A website that allows users to bet fake currency on 1 on 1 fights, the outcomes of which are determined by chance and described by AI.

Roles
- [ ] Admin: can create/edit/delete fighters as well as set up matches between fighters. They can also edit users
- [ ] User: can view fighter details and fights, as well as bet their coins on matches and receive a payout if they bet correctly
- [ ] Anonymous user: can only view fighters and matches, but cannot bet

Entities
- [ ] Fighter: all fighters are based off of famous people/characters/creatures so the AI will be able to describe the fights in an entertaining way. Each fighter’s image, height, weight, and win/loss record will be visible to users. fighters will also have a hidden “power level”, and the ratio between the levels of each fighter will determine the betting odds/likelihood of each fighter winning 
- [ ] Match: these will be created by admin between 2 fighters, and be set up with a match date at which point the outcome will be decided and all who bet will be paid out. Fight outcomes are decided by randomly selecting a winner  based on the betting odds and prompting the AI to describe a fight with the winner coming out on top.
- [ ] User: each user will have an account to track the amount of coins they have.
